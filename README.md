# AI-Image-Generator
AI Image Generator
This project is a web-based AI Image Generator built with HTML, CSS, and JavaScript, integrating the Hugging Face Inference API. Users can enter a text prompt, and the app will generate a high-quality image based on that input using powerful models like Stable Diffusion.

🚀 Features
Clean and responsive user interface

Text-to-image generation in real-time

Powered by Hugging Face's AI models

Loading animation during generation

Easy to customize and deploy

🛠️ Technologies Used
HTML5

CSS3

JavaScript (ES6)

Hugging Face Inference API
